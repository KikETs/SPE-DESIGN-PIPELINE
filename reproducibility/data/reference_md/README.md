# Reference-stratified MD table

`reference_md_selection_status_120.csv` preserves all 120 selected reference
systems. It joins selection metadata and structured execution status to the 108
completed static-cNE0 rows. The 12 failed systems remain present with missing
scientific results and their archived failure/status fields; no values are
imputed.
