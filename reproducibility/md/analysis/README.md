# MD analysis execution sequence

The historical workflow is a set of scripts rather than one monolithic command.
Run it only when the original generated/reference run trees and trajectories are
available. The compact numerical outputs are already released and are not
regenerated by the repository integrity tests.

Canonical script prefix:
`MY_PAPER_RELATED/gromacs_eval_pred_conductivity/reproducibility/static_cne0_release/analysis/`.

1. **RDF and cutoff extraction.** `rdf_peak_tau0_replica_eval.py` calls
   `gmx rdf` and records both peak and first-minimum values. Its RDF output can
   supply the cutoff table, but its peak/zero-persistence conductivity branch is
   a sensitivity analysis, not the manuscript result.
2. **Manuscript association and static cNE0.** `manuscript_static_cne0.py`
   consumes the archived first-minimum tables and trajectories, applies
   `Li_TFSI_O_contacts_ge_2`, builds the frame-static graph, uses
   `z_ij = i - j`, and calculates cNE0 and NE values.
3. **Replica and candidate aggregation.** The same script writes
   `replica_results.csv`, `candidate_means.csv`, candidate-level group summaries,
   and pairwise tests. Generated candidate values are arithmetic means of three
   linear-conductivity replica values.
4. **Reference comparison.** The same script retains the completed reference
   trajectories and writes group/overall MALogE, Spearman, Kendall,
   Mann-Whitney, and Cliff's-delta statistics.
5. **MSD fit diagnostics.** `msd_fit_r2_expanded.py` reads each replica's
   `msd_li.xvg`, `msd_tfsi_N.xvg`, and analysis fit window; it writes 360
   species/replica fits plus candidate summaries.
6. **MSD beta diagnostics.** `msd_beta_windows.py` computes rolling slopes of
   `log(MSD)` against `log(t)`, with defaults 31 points, beta 0.9-1.1, and a
   minimum accepted duration of 500 ps.
7. **Release build.** The existing
   `MY_PAPER_RELATED/gromacs_eval_pred_conductivity/scripts/release/build_static_cne0_release.py`
   freezes the compact inputs and numerical outputs after its quality checks.

From `MY_PAPER_RELATED/gromacs_eval_pred_conductivity/`, the archived command
forms are:

```bash
python scripts/analysis/manuscript_static_cne0.py \
  --dataset all \
  --reference-base /path/to/eval_top10_bottom10_stratified100 \
  --temperature-k 353 --frame-spacing-ps 1.0 --max-cluster-size 101 --workers 8

python scripts/analysis/msd_fit_r2_expanded.py

python scripts/analysis/msd_beta_windows.py \
  --pred-runs-dir runs \
  --ref-runs-dir /path/to/eval_top10_bottom10_stratified100/runs \
  --expected-pred-replicas 180 --expected-ref-trajs 108 \
  --out-dir github_results/latest_notebook_manifest_60/s14c_msd_beta_windows
```

The reference run-tree path is external to this checkout. Absence of that tree
does not invalidate the released 108-row compact result, but prevents a fresh
trajectory-level rerun on a clean clone until the external MD archive is
available.
