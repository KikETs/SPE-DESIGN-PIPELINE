# Random-seed disclosure

`generated_md_replica_seeds.csv` has one row for each of the 180 generated
production replicas.

- Replica 1 uses `continuation_from_equilibrated_state`; production does not
  generate new velocities (`gen-vel = no`).
- Replica 2 uses `gen-seed = 730002`.
- Replica 3 uses `gen-seed = 730003`.

The latter values are generated by
`MY_PAPER_RELATED/gromacs_eval_pred_conductivity/reproducibility/static_cne0_release/workflow/phase_scripts/gromacs_new_phase_md.py`
as `730000 + replica_idx` and are confirmed in the representative production
MDPs. They are reused by candidate but produce distinct systems because each
candidate has a distinct starting configuration.

Initial equilibration uses `gen-seed = -1`; the concrete GROMACS-generated seed
was not recovered. Analysis/bootstrap seeds are separate and remain in their
analysis scripts and output tables.
