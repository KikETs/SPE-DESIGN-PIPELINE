# ACPYPE invocation and topology routes

## Direct polymer topology

The direct route repairs the polymer PDB geometry when needed, then runs ACPYPE with gas-phase charges and integer polymer charge zero:

```bash
acpype -i structures/Traj_912118_chain_fix_acpypefix.pdb \
  -b polymer -c gas -o gmx -n 0
```

The reference example uses the same command structure with `Traj_13430_chain_fix_acpypefix.pdb`. A validated shared cache may be reused when the PSMILES, DP, charge method, atom type, and total charge match.

## TFSI topology

```bash
acpype -i structures/tfsi.pdb -b tfsi -c gas -o gmx -n -1
```

The TFSI atomic charges are subsequently replaced by the canonical `lammps_fq07` values, whose molecular total is `-0.7 e`. Li is a monatomic topology with charge `+0.7 e`; it is not generated by ACPYPE.
